# Folio

A thoughtful, tactile reading community for iPhone.

## Project status

The repository is being initialized. The first milestone is a native SwiftUI bookshelf and library flow; authentication, barcode scanning, social features, 3D interactions, and sound will follow in staged implementation.

## Planned stack

- SwiftUI for the native iOS interface
- SceneKit for interactive 3D book previews
- Firebase Authentication and Firestore for accounts and community features
- Google Sign-In for Google authentication
- Open Library for ISBN and book metadata lookup
- GitHub Actions for automated iOS builds

## Building

An Xcode project and build workflow will be added as the native app is implemented. Device IPA signing requires an Apple Developer signing certificate and provisioning profile.
